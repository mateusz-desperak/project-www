# Website Project

## Project Goal
The goal of this project is to design and implement a modern responsive website for a fictive local café 
The system aims to:

- Presentation: Displaying the café's menu, offers, and news fetched from an external API with local caching.
- Interactivity: Providing an interactive FAQ section, menu filtering by categories, and a live clock.
- Reservation System: Allowing users to make table reservations with client-side form validation.

This project was developed as part of an academic course at university.

## How to run
1. Clone or copy the project folder into your local XAMPP `htdocs` directory (`C:\xampp\htdocs\projekt-www`).
2. Start **Apache** and **MySQL** modules in the XAMPP Control Panel.
3. Import the database schema (if applicable) into your local MySQL via phpMyAdmin.
4. Open your browser and navigate to: `http://localhost/projekt-www/index.html` (or use your configured `.htaccess` friendly URLs).
